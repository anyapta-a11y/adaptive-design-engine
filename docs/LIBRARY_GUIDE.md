# Как подготовить свою библиотеку слайдов для ADE

Делается один раз в PowerPoint, примерно 5 минут на слайд. Пример готовой разметки: `examples/library.pptx` (собирается командой `python examples/make_library.py examples/library.pptx`).

## 1. Какие слайды положить
10–15 самых частых типов. Для слайдов с повторяющимися элементами (карточки, этапы, показатели) сверстайте **несколько вариантов по числу элементов**: например, на 2, 3, 4 и 5 карточек. Программа выберет готовый вариант. Сама добавлять элемент она будет, только если подходящего варианта нет, а дизайнер всегда сверстает красивее.

## 2. Заметка к слайду
В самой первой строке заметок к слайду (поле под слайдом) напишите:
```
ade: id=cards-3; family=cards; purpose=Три параллельных преимущества с коротким пояснением
```
- `id` — уникальное короткое имя латиницей.
- `family` — семейство: `title`, `cards`, `process`, `kpi`, `table`, `chart`, `text`. Все варианты карточек — одно семейство `cards`.
- `purpose` — по-русски, для чего этот слайд. По этому описанию Claude выбирает слайд, поэтому пишите конкретно.

## 3. Имена фигур
Главная → Упорядочить → **Область выделения** (Selection Pane). Двойной щелчок по имени, чтобы переименовать.

| Как назвать | Что это |
|---|---|
| `title`, `subtitle`, `body`, `note` | Текстовые поля слайда |
| `item[1]`, `item[2]`, … | Повторяемый элемент: карточка, этап, показатель. Лучше группа. Номера слева направо или сверху вниз |
| `item[1].title`, `item[1].body` | Поля внутри карточки |
| `item[1].value`, `item[1].label` | Число и подпись показателя |
| `item[1].num`, `item[1].label` | Номер и подпись этапа процесса |
| `connector[1]`, … | Стрелка или линия между этапами 1 и 2 и так далее |
| `table` | Таблица (первая строка — шапка) |
| `chart` | Диаграмма (только настоящая диаграмма PowerPoint, не картинка) |

Всё, что не переименовано, считается оформлением и не меняется: фон, логотипы, декоративные линии.

## 4. Правила, от которых зависит качество
- Таблица, диаграмма и текст должны быть настоящими объектами PowerPoint, не картинками.
- Внутри одного варианта все карточки одинакового размера и стиля. Программа копирует последнюю карточку.
- Размер шрифта в макете — это максимальный. Программа может уменьшить его не больше чем до 75%, если не хватает места.
- Текст-заглушку в полях оставьте: по нему видно, где какое поле.

## 5. Проверка разметки
`python -m ade catalog library.pptx` — если в разметке ошибка (два одинаковых `id`, пропущен `item[2]`), команда скажет, где именно.
