# Замер Graphify на репозитории ADE (2026-10-14)

Условия: Graphify 0.9.90, карта только по коду и Markdown (`graphify update .`, без LLM, 1 с, 0 токенов), 46 файлов, ~1 900 строк Python. Два одинаковых субагента (sonnet), три одинаковых вопроса о коде (порядок вызовов при копировании диаграммы; что затронет смена сигнатуры `renumber()`; где проверяется разрыв слов и нижний порог кегля).

| | С картой (graphify query/explain/affected + точечный Read) | Без карты (rg/Grep + точечный Read) |
|---|---|---|
| Токены субагента | 78 483 | 71 489 |
| Вызовы инструментов | 14 | 13 |
| Время | 51 с | 29 с |
| Правильность ответов | все три верны; в п.1 часть цепочки не дочитана | все три верны, полнее |

Вывод (**точно** для этого замера, n=1 на вариант — не статистика): на текущем размере проекта карта **не экономит**, а тратит на ~10% больше токенов и почти вдвое больше времени. Ответ `graphify query` сам по себе ~2 000 токенов, а `rg` по маленькому коду дешевле.

Решение: Graphify установлен по решению владельца (D-004), карта пересобирается хуком при старте сессии (стоит 0 токенов, т.к. skill Graphify не загружается — используется только CLI). Агентам **не** предписано использовать карту по умолчанию. Повторить этот замер при >150 файлах кода или >10k строк.
