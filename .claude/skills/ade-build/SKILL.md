# ADE: Word → презентация по библиотеке слайдов

Ты выбираешь слайды и раскладываешь текст. Всё остальное (варианты, клонирование, таблицы, диаграммы, подгонка, проверка) делает программа `ade`. Не правь PPTX сам.

## Входы
- DOCX с контентом.
- Библиотека `library.pptx`, размеченная по `docs/ARCHITECTURE.md` §1. Если не указана — `examples/library.pptx` (собрать: `python examples/make_library.py examples/library.pptx`).

## Шаги
1. Каталог (не открывай library.pptx напрямую — дорого и не нужно):
   `python -m ade catalog <library.pptx> > /tmp/ade/catalog.json`
   Если команда падает с ошибкой разметки — покажи её пользователю и остановись.
2. Документ: `python .claude/skills/ade-build/scripts/read_docx.py <doc.docx> > /tmp/ade/doc.md`, прочитай `doc.md`.
3. Составь `/tmp/ade/plan.json` по контракту `docs/ARCHITECTURE.md` §3:
   - Один смысловой блок документа → один слайд. Выбирай `family` по `purpose` из каталога:
     перечень однотипных тезисов → `cards`; последовательность шагов/этапов → `process`; 2–4 ключевых числа → `kpi`; таблица → `table`; ряд чисел по категориям → `chart`; связный текст → `text`.
   - Указывай `family`, а не `id`, если подходит несколько вариантов: программа сама выберет вариант по числу элементов.
   - **Текст переносится дословно.** Не сокращай, не перефразируй, не исправляй, не добавляй. Можно только разложить по полям (заголовок пункта / пояснение), если в документе это явно разделено (двоеточие, тире, перенос строки, жирный).
   - Если в блоке больше элементов, чем `max` семейства в каталоге, раздели блок на два слайда одного семейства и продублируй заголовок с пометкой «(продолжение)» — это единственное допустимое добавление текста.
   - Числа для диаграмм бери только из документа. Нет чисел — не делай диаграмму.
4. Сборка и проверка:
   ```
   python -m ade build --library <library.pptx> --plan /tmp/ade/plan.json --out <out.pptx>
   python -m ade qa <out.pptx> --plan /tmp/ade/plan.json --pdf
   ```
5. Если QA = FAIL: прочитай `fails`, исправь **план** (другой вариант семейства, разделить блок на два слайда), повтори шаг 4. Не больше 2 повторов. Если всё ещё FAIL — отдай результат с честным списком проблем.
6. Ответ пользователю: путь к PPTX и PDF, число слайдов, статус QA, список WARN (где уменьшен кегль, где элемент добавлен клонированием, а не готовым вариантом) и блоки документа, которые не удалось уложить.

## Запреты
- Не менять стили, цвета, шрифты, позиции фигур вручную.
- Не вставлять картинки вместо таблиц и диаграмм.
- Не терять контент: каждая строка документа, попавшая в план, должна быть в презентации (это проверяет QA).
