# Библиотека на реальном макете (остановлено 2026-10-14)

Анна закрыла проект и решила начать заново. Здесь сохранено то, что успели сделать. Сам макет и файлы из него в репозиторий не кладутся.
- `redraw.py`: перерисовывает нарисованные в Canva диаграмму и таблицы (слайды 3, 5, 8) нативными объектами PowerPoint.
- `markup.py`: разметка ADE для 10 слайдов (заметки `ade:`, имена фигур), картинки номеров страниц в оглавлении заменены текстом, номера страниц сделаны полем.
- `content.py`, `make_demo.py`: синтетический Word и plan.json для проверки.
- Незавершённая работа над движком v0.3 (именованные слоты в группах, `chart_2`, `**жирный**`, `static_text`): `ade/slots.py`, `tests/test_v03.py`. Тесты проходят (45), но v0.3 не принята и не проверена QA.
